# Next.js 14+ Personal Portfolio Template

Selamat datang di Template Portofolio Next.js 14+! Template ini dirancang untuk membantu Anda membuat portofolio profesional dengan cepat dan mudah.

## Fitur Utama

- **Dukungan Multi Bahasa**: Template mendukung beberapa bahasa termasuk Inggris, Arab, dan Indonesia.
- **Dukungan RTL**: Mendukung tata letak dari kanan ke kiri (RTL) untuk bahasa seperti Arab.
- **Form Kontak Fungsional**: Form kontak yang terhubung dengan backend.
- **Pilihan Tema Gelap dan Terang**: Dukungan tema gelap dan terang untuk tampilan yang lebih baik.
- **Desain Responsif**: Sepenuhnya responsif dan tampak hebat di perangkat apa pun.
- **Konsultasi Produk**: Kami menyediakan layanan konsultasi untuk membantu Anda mengoptimalkan penggunaan template ini.

## Persyaratan Sistem

- Node.js (v20+)
- npm (10+)
- Next.js 14+

## Instalasi

### 1. Menginstal Node.js dan npm

Jika Anda belum menginstal Node.js dan npm, ikuti langkah-langkah berikut:

1. **Unduh Node.js**: Kunjungi [situs resmi Node.js](https://nodejs.org/) dan unduh versi terbaru sesuai sistem operasi Anda.
2. **Instal Node.js**: Ikuti petunjuk instalasi yang ada di situs untuk sistem operasi Anda.
3. **Verifikasi Instalasi**: Buka terminal atau command prompt dan ketik perintah berikut untuk memastikan Node.js dan npm telah terinstal dengan benar:

    ```bash
    node -v
    npm -v
    ```
